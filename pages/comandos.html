Comandos de console

Todos os comandos GM do jogo explicados. Escreva o que você quer fazer e o site acha o comando.

Como usar

  1. Abra o console do jogo com a tecla ` ou ~ (à esquerda do 1).
  2. Em servidor, entre como admin primeiro: gm Key suasenha (a senha é a do -adminpsw= do servidor).
  3. Digite gm + o comando + os valores, separados por espaço. Ex.: gm AddExp 10000.
  4. Os comandos marcados como RCON são do console do servidor (janela do servidor ou programa de RCON), sem o gm.
